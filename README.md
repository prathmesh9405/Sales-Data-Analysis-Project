📊 Sales Data Analysis Project
🚀 Project Overview

This is an end-to-end Sales Data Analysis project created using Excel, MySQL, Python, and Power BI.

The project analyzes a realistic dataset containing 1,000 sales records to identify sales trends, product performance, customer behaviour, regional performance, and profitability.
